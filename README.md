# Криптоанализатор (Шифр Цезаря)

## Описание проекта

Данный проект представляет собой консольное приложение для работы с шифром Цезаря.

Программа позволяет:
- шифровать текст
- расшифровывать текст с использованием ключа

---

## Как работает программа

В основе лежит классический шифр Цезаря — каждый символ текста сдвигается на заданное количество позиций по алфавиту.

Пример:
ключ = 3
а → г
б → д

---

## Алфавит

Программа использует русский алфавит и базовые символы:


а-я, ё, пробел, . , « » " ' : - ! ?


Если во входном тексте встречаются символы, не входящие в этот алфавит — они игнорируются и остаются без изменений.

---

## Режимы работы

Программа поддерживает два основных режима:

### 1. Шифрование
- принимает файл с исходным текстом
- принимает ключ
- записывает зашифрованный текст в новый файл

### 2. Расшифровка
- принимает зашифрованный файл
- принимает ключ
- восстанавливает исходный текст

---

## Работа с файлами

Программа:
- читает текст из входного файла
- обрабатывает его
- записывает результат в выходной файл

---

## Как запустить

1. Запустить класс `MainApp`
2. Выбрать режим работы:
    - 1 — шифрование
    - 2 — расшифровка
3. Ввести:
    - путь к входному файлу
    - путь к выходному файлу
    - ключ

---

## Ограничения

- ключ приводится к диапазону алфавита
- программа работает с текстовыми файлами
- символы вне алфавита не изменяются
